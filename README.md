# PharmConnect

Pharmacy student portal with an academic calendar, curriculum flowchart, faculty directory, dosage tools, tuition calculator, study materials, and announcements.

## Getting started

```bash
npm install
npm run dev
```

## Available commands

- `npm run build` — create a production build
- `npm run lint` — run ESLint
- `npm run typecheck` — check TypeScript types
- `npm run server` — start the optional health-check server (defaults to port 3000)
